# GODLY MOST — أرشيف موست الدراسي

أرشيف دراسي مفتوح لقسم الأمن السيبراني — محاضرات وملخصات منظمة (نظري + مختبر)،
بتصميم أسود × أبيض خفيف ومرتّب.

**Live:** https://godlymost.vercel.app

## التقنيات

- HTML + CSS + Vanilla JS — بدون أي build step
- خطوط: IBM Plex Sans Arabic + IBM Plex Mono
- RTL بالكامل، متجاوب مع الموبايل

## المحتوى

| المادة | الحالة |
|---|---|
| ⚡ أسس الإلكترونيك | ✅ ٦ محاضرات (٣ نظري + ٣ مختبر) |
| 📊 هياكل البيانات | ✅ ٥ محاضرات (٣ نظري + ٢ مختبر) |
| ⌨️💻🔌🔢📐🏛️ بقية المواد | ⏳ قيد التحضير |

## التطوير محلياً

